# 错误码参考

> 调用出错了？对照下面的状态码找原因。

---

## 401 — 密钥不对

**你会看到**：`Invalid token`

**怎么修**：
1. 检查 API Key 是不是复制全了（以 `sk-` 开头）
2. 检查密钥有没有被禁用或删除
3. OpenAI 格式用 `Authorization: Bearer sk-xxx`
4. Claude 格式用 `x-api-key: sk-xxx`（别搞混了）

---

## 402 — 没钱了

**你会看到**：`Insufficient balance`

**怎么修**：去控制台 → 钱包 → 充值。

---

## 403 — 没权限

**你会看到**：`Model not allowed for this token`

**怎么修**：
- 你创建密钥时可能限制了可用模型，去控制台看看密钥设置
- 或者设了 IP 白名单，换个网络就不行了

---

## 400 — 请求格式错了

**你会看到**：`invalid JSON request body`

**怎么修**：你发的 JSON 有语法错误（多了逗号、少了引号之类的）。

---

## 503 — 模型不存在 / 渠道挂了

**你会看到**：`模型 xxx 无可用渠道`

**怎么修**：
1. 先检查模型名有没有打错（区分大小写！）
2. 如果名字没错，说明上游暂时挂了，等几分钟重试，或换个模型

当前可用模型：`deepseek-v4-flash`、`deepseek-v4-pro`、`kimi-k2.7-code`、`kimi/kimi-k3`、`qwen3.7-flash`、`qwen3.7-plus`、`qwen3.7-max`、`glm-5.2`、`MiniMax-M2.5`、`MiniMax/MiniMax-M3`

---

## 429 — 请求太频繁

**你会看到**：`Rate limit exceeded`

**怎么修**：慢点发请求。如果是程序在跑，加个重试逻辑：

```python
import time

for attempt in range(3):
    try:
        # 你的调用代码
        break
    except Exception:
        time.sleep(2 ** attempt)  # 等 1s、2s、4s 再试
```

---

## 500 — 服务器内部错误

**两种情况**：
- 如果是 `field messages is required`：你请求里少了必填字段（model、messages）
- 如果是其他：上游 AI 服务临时抽风，等 1-2 分钟重试

---

## 502 / 504 — 网关错误 / 超时

**怎么修**：
- 等几分钟重试
- 如果是超时，试试加 `"stream": true` 用流式输出
- 持续出现就联系我们

---

## 快速排查清单

遇到任何错误，按这个顺序检查：

1. ✅ API Key 对不对（`sk-` 开头，没多余空格）
2. ✅ 模型名对不对（大小写、横杠）
3. ✅ 余额够不够
4. ✅ Base URL 对不对（`https://www.aytdai.com/v1`）
5. ✅ 请求格式对不对（JSON 合法、必填字段都有）

**还是不行？** 用 curl 测一下，排除客户端问题：

```bash
curl https://www.aytdai.com/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"hi"}]}'
```

如果 curl 能通但你的工具不行，说明是工具配置问题。
