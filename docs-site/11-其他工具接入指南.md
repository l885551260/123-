# 其他工具接入指南

> 在任意支持自定义 OpenAI 兼容或 Anthropic 兼容端点的 AI 工具中接入本平台模型。

上面已经覆盖了主流 AI 编程工具的接入步骤。如果你使用的工具不在列表里，但支持自定义 Base URL + API Key，照下面的值填即可。

---

## 配置参考

本平台同时提供两种兼容协议，你的工具支持哪种就选哪种。

### OpenAI 兼容协议

| 字段 | 值 |
|------|-----|
| **Provider** | `OpenAI Compatible`（有的工具叫 `Custom` 或 `OpenAI-format`） |
| **Base URL** | `https://www.aytdai.com/v1` |
| **API Key** | 平台 API Key（登录 [控制台](https://www.aytdai.com) 创建） |
| **Model ID** | `deepseek-v4-pro`（推荐） |

### Anthropic 兼容协议

| 字段 | 值 |
|------|-----|
| **Provider** | `Anthropic Compatible`（有的工具叫 `Claude` 或 `Custom Anthropic`） |
| **Base URL** | `https://www.aytdai.com` |
| **API Key** | 平台 API Key（认证头为 `x-api-key`） |
| **Model ID** | `deepseek-v4-pro`（推荐） |

> **注意**：Anthropic SDK 会自动在 Base URL 后拼接 `/v1/messages`，因此这里填**裸域名**，不带 `/v1`。Claude Code 是例外（它只拼接 `/messages`），详见 [Claude Code 接入指南](Claude-Code接入指南.md)。

### 该选哪种协议

| 工具类型 | 推荐协议 | 常见环境变量 |
|---------|---------|------------|
| Claude Code 风格（为 Anthropic 设计的 TUI/CLI） | Anthropic 兼容 | `ANTHROPIC_BASE_URL` + `ANTHROPIC_AUTH_TOKEN`（Base URL 含 `/v1`） |
| Cursor / Continue / Aider / 各类 OpenAI 格式 IDE 插件 | OpenAI 兼容 | `OPENAI_BASE_URL` + `OPENAI_API_KEY` |
| 两种都支持的工具 | 任选 | |

### 可用模型

| 模型 ID | 说明 |
|---------|------|
| `deepseek-v4-pro` | 更强推理能力（推荐） |
| `deepseek-v4-flash` | 快速响应，性价比高 |
| `kimi-k2.7-code` | 代码专精，支持图片输入 |
| `kimi/kimi-k3` | Kimi 旗舰 |
| `qwen3.7-max` | 通义千问旗舰 |
| `qwen3.7-plus` | 通义千问增强 |
| `qwen3.7-flash` | 通义千问快速 |
| `glm-5.2` | 智谱 GLM |
| `MiniMax-M2.5` | MiniMax |
| `MiniMax/MiniMax-M3` | MiniMax M3 |

> 模型列表以 `GET /v1/models` 返回为准。

## Dify

[**Dify**](https://github.com/langgenius/dify) 是一个开源 LLM 应用开发平台，集成工作流、RAG、Agent 与可观测性。

1. 打开 [Dify Cloud](https://cloud.dify.ai)，登录后进入 **设置 → 工作空间 → 模型供应商**
2. 找到 **OpenAI-API-compatible** 供应商，点击添加
3. 填写：模型名称 `deepseek-v4-pro`、API Key（平台 Key）、API endpoint URL `https://www.aytdai.com/v1`
4. 保存后即可在工作流中调用

## Cherry Studio

[**Cherry Studio**](https://github.com/CherryHQ/cherry-studio) 是一个开源桌面客户端，支持 50+ LLM 服务商，内置 MCP 服务器和 300+ 智能助手。

1. 按 [Cherry Studio 官方文档](https://docs.cherry-ai.com/cherry-studio/download) 完成安装
2. 打开 Cherry Studio → 点 **Choose other Providers** → 选择 **OpenAI**（或自定义服务商）
3. **API Host** 填 `https://www.aytdai.com/v1`，**API Key** 填平台 Key，点 **Check** 验证连接
4. 模型列表中选 `deepseek-v4-pro` 即可使用

## Xcode

[**Xcode**](https://developer.apple.com/xcode/) 是 Apple 官方 IDE，支持 macOS / iOS / iPadOS / watchOS / visionOS 开发，内置 Coding Intelligence。

1. 从 [Mac App Store](https://apps.apple.com/us/app/xcode/id497799835) 安装 Xcode 26 或更新版本
2. 打开 Xcode → 顶部菜单 **Xcode → Settings → Intelligence → Add a Model Provider**，选 **Internet Hosted** 标签页，填：
   - **URL**：`https://www.aytdai.com`（裸 host，不带任何 path）
   - **API Key Header**：`Authorization`
   - **API Key**：`Bearer <你的平台 API Key>`（`Bearer` 后只有一个空格再接 Key）
   - **Description**：`AytdAI`（任意）
3. 点 **Add**，回 Intelligence 面板启用 `deepseek-v4-pro`
4. 打开任意项目，按 **⌘+0** 唤出 Coding Assistant，左上角选模型即可

## Kilo Code

[**Kilo Code**](https://github.com/Kilo-Org/kilocode) 是开源的 VS Code AI 编程 Agent 插件，支持多家 LLM 服务商和 MCP 服务器。

> 使用前先清空 `ANTHROPIC_AUTH_TOKEN` 和 `ANTHROPIC_BASE_URL` 环境变量，否则会覆盖配置。

1. 在 VS Code 扩展面板搜索 `Kilo Code` 安装
2. 打开 Kilo Code → **Settings**：
   - **API Provider** 选 `OpenAI Compatible`
   - **Base URL** 填 `https://www.aytdai.com/v1`
   - **API Key** 填平台 Key
   - **Model** 填 `deepseek-v4-pro`
3. 依次点 **Save** + **Done** 保存

## Zed

[**Zed**](https://github.com/zed-industries/zed) 是 Atom 创始团队打造的开源高性能多人协同代码编辑器，由 Rust 编写。

1. 按 [Zed 官方文档](https://zedhub.org/getting-started) 完成安装
2. 设置 → **LLM Provider** → **+Add Provider** → 选 **OpenAI**，填：
   - **API URL**：`https://www.aytdai.com/v1`
   - **API Key**：平台 API Key
   - **Model Name**：`deepseek-v4-pro`
3. 点 **Save Provider** 保存，回 LLM Provider 列表点击新加的条目，再次输入 API Key 并按回车确认
4. 回智能体面板右下角 **Select a Model** 选 `deepseek-v4-pro` 即可使用

## Grok CLI

[**Grok CLI**](https://github.com/superagent-ai/grok-cli) 是开源终端编程 Agent，可接入任意 OpenAI 兼容服务商。

> 使用前先清空 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL` 环境变量。

```bash
npm install -g @vibe-kit/grok-cli
```

设环境变量并启动：

```bash
export GROK_BASE_URL=https://www.aytdai.com/v1
export GROK_API_KEY=sk-...   # 平台 API Key
grok --model deepseek-v4-pro
```

## Droid

[**Droid**](https://factory.ai) 是 Factory 官方终端编程 Agent，可与 IDE 和团队协作工具集成。

> 必须先清空 `ANTHROPIC_AUTH_TOKEN` 环境变量。配置文件路径是 `~/.factory/config.json`。

1. 安装：

```bash
curl -fsSL https://app.factory.ai/cli | sh        # macOS / Linux
# Windows:  irm https://app.factory.ai/cli/windows | iex
```

2. 在 `~/.factory/config.json` 加入：

```json
{
  "custom_models": [{
    "model_display_name": "deepseek-v4-pro",
    "model": "deepseek-v4-pro",
    "base_url": "https://www.aytdai.com",
    "api_key": "<你的平台 API Key>",
    "provider": "anthropic",
    "max_tokens": 64000
  }]
}
```

3. 启动 `droid`，`/model` 选 `deepseek-v4-pro` 即可使用

## MonkeyCode

[**MonkeyCode**](https://github.com/chaitin/MonkeyCode) 是长亭科技出品的企业级 AI 开发平台，Code Agent 兼容 Codex / Claude Code / OpenCode。

1. 访问 [MonkeyCode 官网](https://monkeycode-ai.com) 登录
2. 右下角 **配置** → **AI 大模型** → **绑定**
3. 填写：
   - **API 地址**：`https://www.aytdai.com`
   - **API Key**：平台 API Key
   - **接口格式**：`anthropic`
   - **模型名称**：`deepseek-v4-pro`
4. **保存** 后回主界面即可使用

## Open WebUI

[**Open WebUI**](https://github.com/open-webui/open-webui) 是自托管的开源 AI 聊天平台，支持离线运行、RAG 和多模型 runner。

1. 安装（要求 **Python 3.11**）：

```bash
pip install open-webui
open-webui serve
```

2. 浏览器打开 http://localhost:8080，按提示创建本地管理员账号
3. 右上角头像 → **Admin Panel** → **Settings** → **Connections**，在 **OpenAI** 一栏点 **➕ Add Connection**，填：
   - **URL**：`https://www.aytdai.com/v1`
   - **Auth**（Bearer 模式）：平台 API Key
4. 点 **Save** 后回到聊天界面，顶部模型选择器选 `deepseek-v4-pro` 即可对话

## OpenHands

[**OpenHands**](https://github.com/All-Hands-AI/OpenHands)（前身 OpenDevin）是 All-Hands-AI 出品的开源 AI 编程 Agent，提供 TUI、网页 GUI 和 IDE 集成。

1. 安装：

```bash
pipx install openhands
```

2. 配置（把 `sk-...` 换成你的平台 API Key）：

```bash
pipx run --spec openhands python -c '
import sys
from openhands_cli.stores.agent_store import AgentStore
AgentStore().create_and_save_from_settings(
    llm_api_key=sys.argv[1],
    settings={"llm_model": "openai/deepseek-v4-pro",
              "llm_base_url": "https://www.aytdai.com/v1"},
)
' sk-...
```

3. 启动：

```bash
openhands
```

## LangChain

[**LangChain**](https://github.com/langchain-ai/langchain) 是开源 LLM 应用开发框架，提供模型适配器、检索、Agent 与可观测性能力。

1. 安装：

```bash
pip install langchain-openai
```

2. 通过 OpenAI 兼容适配器接入（把 `sk-...` 换成你的平台 API Key）：

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="deepseek-v4-pro",
    api_key="sk-...",
    base_url="https://www.aytdai.com/v1",
)
print(llm.invoke("Hello").content)
```
