# 其他工具接入指南

> 你用的工具不在前面的列表里？只要它支持自定义 OpenAI 或 Anthropic 端点，就能接。

---

## 万能配置（记住这三样就行）

| 填什么 | 填多少 |
|--------|--------|
| Provider 类型 | OpenAI Compatible（有的叫 Custom） |
| Base URL | `https://www.aytdai.com/v1` |
| API Key | 你的 `sk-xxx` 密钥 |
| 模型 | `deepseek-v4-pro`（推荐） |

> 密钥在 [控制台](https://www.aytdai.com) → 创建API密钥 获取。完整模型列表看 [首页](/)。

如果你的工具只支持 Anthropic 格式：Base URL 填 `https://www.aytdai.com`（不带 /v1），认证头用 `x-api-key`。

## Cherry Studio

[Cherry Studio](https://github.com/CherryHQ/cherry-studio) — 开源桌面客户端，支持 50+ 服务商。

1. 安装后打开 → 点 **Choose other Providers** → 选 **OpenAI**
2. **API Host** 填 `https://www.aytdai.com/v1`，**API Key** 填密钥
3. 点 **Check** 验证 → 选模型 `deepseek-v4-pro` 开聊

---

## Dify

[Dify](https://github.com/langgenius/dify) — 开源 LLM 应用平台（工作流、RAG、Agent）。

1. 打开 [Dify Cloud](https://cloud.dify.ai) → 设置 → 模型供应商
2. 找 **OpenAI-API-compatible**，点添加
3. 填：模型名 `deepseek-v4-pro`、API Key、endpoint `https://www.aytdai.com/v1`
4. 保存，在工作流中调用

---

## Zed

[Zed](https://github.com/zed-industries/zed) — Rust 写的高性能代码编辑器。

1. 设置 → LLM Provider → +Add Provider → 选 OpenAI
2. API URL：`https://www.aytdai.com/v1`，API Key：你的密钥
3. Save Provider → 选模型 `deepseek-v4-pro`

---

## Kilo Code

[Kilo Code](https://github.com/Kilo-Org/kilocode) — VS Code AI 编程插件。

> 先清掉 `ANTHROPIC_AUTH_TOKEN` 和 `ANTHROPIC_BASE_URL` 环境变量。

1. VS Code 扩展搜 `Kilo Code` 安装
2. Settings → API Provider 选 `OpenAI Compatible`
3. Base URL：`https://www.aytdai.com/v1`，API Key：密钥，Model：`deepseek-v4-pro`
4. Save + Done

---

## Xcode

Apple 官方 IDE（需 Xcode 26+）。

1. Xcode → Settings → Intelligence → Add a Model Provider → Internet Hosted
2. URL：`https://www.aytdai.com`（裸域名，不带路径）
3. API Key Header：`Authorization`
4. API Key：`Bearer sk-你的密钥`（Bearer 后一个空格再接密钥）
5. Add → 启用 `deepseek-v4-pro` → ⌘+0 唤出助手

## Open WebUI

[Open WebUI](https://github.com/open-webui/open-webui) — 自托管 AI 聊天平台。

```bash
pip install open-webui
open-webui serve
```

浏览器打开 http://localhost:8080 → Admin Panel → Settings → Connections → OpenAI → Add Connection：
- URL：`https://www.aytdai.com/v1`
- Auth：你的密钥

## Droid

[Factory Droid](https://factory.ai) — 终端编程 Agent。

> 先清掉 `ANTHROPIC_AUTH_TOKEN` 环境变量。

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

编辑 `~/.factory/config.json`：

```json
{
  "custom_models": [{
    "model_display_name": "deepseek-v4-pro",
    "model": "deepseek-v4-pro",
    "base_url": "https://www.aytdai.com",
    "api_key": "sk-你的密钥",
    "provider": "anthropic",
    "max_tokens": 64000
  }]
}
```

启动 `droid`，`/model` 选模型即可。

## MonkeyCode

[MonkeyCode](https://monkeycode-ai.com) — 长亭科技的企业级 AI 开发平台。

1. 登录 → 右下角配置 → AI 大模型 → 绑定
2. API 地址：`https://www.aytdai.com`，接口格式：`anthropic`
3. API Key：密钥，模型：`deepseek-v4-pro`
4. 保存

## OpenHands

[OpenHands](https://github.com/All-Hands-AI/OpenHands) — 开源 AI 编程 Agent。

```bash
pipx install openhands
```

配置（把 `sk-...` 换成你的密钥）：

```bash
pipx run --spec openhands python -c '
import sys
from openhands_cli.stores.agent_store import AgentStore
AgentStore().create_and_save_from_settings(
    llm_api_key=sys.argv[1],
    settings={"llm_model": "openai/deepseek-v4-pro",
              "llm_base_url": "https://www.aytdai.com/v1"},
)
' sk-你的密钥
```

启动：`openhands`

## LangChain

```bash
pip install langchain-openai
```

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="deepseek-v4-pro",
    api_key="sk-你的密钥",
    base_url="https://www.aytdai.com/v1",
)
print(llm.invoke("Hello").content)
```
