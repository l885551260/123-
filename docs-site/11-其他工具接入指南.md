# 其他工具接入指南

> 适用于未在前述专项指南中列出的工具。只要工具支持自定义 OpenAI 兼容或 Anthropic 兼容端点，即可接入本平台模型。

---

## 通用配置参数

无论使用何种工具，以下为核心配置项：

| 配置项 | 值 |
|--------|-----|
| Provider 类型 | OpenAI Compatible（部分工具称为 Custom） |
| Base URL（OpenAI 格式） | `https://www.aytdai.com/v1` |
| Base URL（Anthropic 格式） | `https://www.aytdai.com`（不带 `/v1`） |
| API Key | 本平台签发的 `sk-` 前缀密钥 |
| 推荐模型 | `deepseek-v4-pro` |

【补充说明：OpenAI 兼容协议与 Anthropic 协议的 Base URL 格式不同。若工具基于 Anthropic Messages API 通信，Base URL 为裸域名（不含 `/v1`），认证头可能为 `x-api-key` 而非 `Authorization: Bearer`。具体取值以工具文档为准。】

API Key 获取方式：登录 [控制台](https://www.aytdai.com) → 创建 API 密钥。

完整可用模型列表见 [首页](/)。

## Cherry Studio

[Cherry Studio](https://github.com/CherryHQ/cherry-studio) 为开源桌面 AI 客户端，支持 50+ 服务商。

### 执行步骤

1. 安装后打开，点击 **Choose other Providers**
2. 选择 **OpenAI**
3. **API Host** 填入：`https://www.aytdai.com/v1`
4. **API Key** 填入本平台的 `sk-` 前缀密钥
5. 点击 **Check** 验证连接
6. 选择模型 `deepseek-v4-pro`，开始使用

### 预期结果

Check 验证通过后，模型列表中出现可选的 `deepseek-v4-pro`。

## Dify

[Dify](https://github.com/langgenius/dify) 为开源 LLM 应用平台，支持工作流、RAG、Agent 等能力。

### 执行步骤

1. 打开 [Dify Cloud](https://cloud.dify.ai)（或自部署实例）
2. 进入 **设置** → **模型供应商**
3. 找到 **OpenAI-API-compatible**，点击添加
4. 填写：
   - 模型名：`deepseek-v4-pro`
   - API Key：本平台的 `sk-` 前缀密钥
   - Endpoint URL：`https://www.aytdai.com/v1`
5. 保存配置

### 预期结果

在 Dify 工作流或应用中，可从模型列表选择 `deepseek-v4-pro` 并成功调用。

   - **Model**：`deepseek-v4-pro`
4. 点击 **Save**，开始对话

## Xcode

Apple 官方 IDE（需 Xcode 26+，macOS）。

### 执行步骤

1. Xcode → **Settings** → **Intelligence** → 点击 **Add a Model Provider**
2. 选择 **Internet Hosted**
3. 填写：
   - **URL**：`https://www.aytdai.com`（裸域名，不带路径）
   - **API Key Header**：`Authorization`
   - **API Key**：`Bearer sk-你的密钥`（`Bearer` 后一个空格再接密钥）
4. 点击 **Add**
5. 启用模型 `deepseek-v4-pro`
6. 使用 `⌘+0` 唤出 AI 助手

【补充说明：Xcode 使用裸域名 Base URL + `Authorization` 头中拼接 `Bearer` 前缀的认证方式，与常规 OpenAI 兼容工具的配置方式不同。请注意 API Key 字段的完整格式。】

## Factory Droid

[Factory Droid](https://factory.ai) 为终端编程 Agent。

### 前置操作

> **⚠️ 重要提示**
>
> 配置前，确保清除系统中残留的 `ANTHROPIC_AUTH_TOKEN` 环境变量（若存在）。

### 安装

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

### 执行步骤

编辑 `~/.factory/config.json`：

```json
{
  "custom_models": [{
    "model_display_name": "deepseek-v4-pro",
    "model": "deepseek-v4-pro",
    "base_url": "https://www.aytdai.com",
    "api_key": "sk-你的密钥",
    "provider": "anthropic",
    "max_tokens": 64000
  }]
}
```

【补充说明：Factory Droid 使用 Anthropic 协议通信，因此 `base_url` 为裸域名（不含 `/v1`），`provider` 字段为 `"anthropic"`。`max_tokens` 可根据实际需求调整。】

### 使用

启动 `droid`，通过 `/model` 命令选择模型。

## 通用异常排查

无论使用何种工具，连接失败时依次检查：

1. API Key 是否以 `sk-` 开头，无多余空格或换行
2. Base URL 是否正确（OpenAI 格式带 `/v1`，Anthropic 格式不带）
3. 账户余额是否充足
4. 网络是否可正常访问 `https://www.aytdai.com`
5. 是否存在残留的官方环境变量覆盖了配置（如 `ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_BASE_URL`）
6. 接口协议是否匹配（部分工具仅支持 OpenAI 格式，不支持 Anthropic 格式；反之亦然）
