# 其他工具接入指南

> 你用的工具不在前面的列表里？只要它支持自定义 OpenAI 或 Anthropic 端点，就能接。

---

## 万能配置（记住这三样就行）

| 填什么 | 填多少 |
|--------|--------|
| Provider 类型 | OpenAI Compatible（有的叫 Custom） |
| Base URL | `https://www.aytdai.com/v1` |
| API Key | 你的 `sk-xxx` 密钥 |
| 模型 | `deepseek-v4-pro`（推荐） |

> 密钥在 [控制台](https://www.aytdai.com) → 创建API密钥 获取。完整模型列表看 [首页](/)。

如果你的工具只支持 Anthropic 格式：Base URL 填 `https://www.aytdai.com`（不带 /v1），认证头用 `x-api-key`。

## Cherry Studio

[Cherry Studio](https://github.com/CherryHQ/cherry-studio) — 开源桌面 AI 客户端，支持 50+ 服务商。

1. 安装后打开 → 点 **Choose other Providers** → 选 **OpenAI**
2. **API Host** 填 `https://www.aytdai.com/v1`，**API Key** 填密钥
3. 点 **Check** 验证通过 → 选模型 `deepseek-v4-pro` 开聊

---

## Dify

[Dify](https://github.com/langgenius/dify) — 开源 LLM 应用平台（工作流、RAG、Agent）。

1. 打开 [Dify Cloud](https://cloud.dify.ai)（或你自部署的 Dify）→ 设置 → 模型供应商
2. 找 **OpenAI-API-compatible**，点添加
3. 填：模型名 `deepseek-v4-pro`、API Key、endpoint URL `https://www.aytdai.com/v1`
4. 保存，在工作流或应用中调用

---

## Zed

[Zed](https://zed.dev) — Rust 写的高性能代码编辑器，内置 AI 助手。

1. 打开设置（`Ctrl+,`）→ LLM Provider → **+Add Provider** → 选 OpenAI
2. API URL：`https://www.aytdai.com/v1`，API Key：你的密钥
3. Save Provider → 在模型列表选 `deepseek-v4-pro`

---

## Kilo Code

[Kilo Code](https://github.com/Kilo-Org/kilocode) — VS Code AI 编程插件（Cline 的分支）。

> 先清掉系统里的 `ANTHROPIC_AUTH_TOKEN` 和 `ANTHROPIC_BASE_URL` 环境变量（如果有的话）。

1. VS Code 扩展商店搜 `Kilo Code` 安装
2. 打开 Kilo Code 面板 → Settings → API Provider 选 **OpenAI Compatible**
3. 填写：
   - Base URL：`https://www.aytdai.com/v1`
   - API Key：你的密钥
   - Model：`deepseek-v4-pro`
4. Save → 开始对话

---

## Xcode

Apple 官方 IDE（需 Xcode 26+，macOS）。

1. Xcode → Settings → Intelligence → **Add a Model Provider** → Internet Hosted
2. URL：`https://www.aytdai.com`（裸域名，不带路径）
3. API Key Header：`Authorization`
4. API Key：`Bearer sk-你的密钥`（Bearer 后一个空格再接密钥）
5. Add → 启用 `deepseek-v4-pro` → `⌘+0` 唤出 AI 助手

## Open WebUI

[Open WebUI](https://github.com/open-webui/open-webui) — 自托管 AI 聊天平台（类 ChatGPT 界面）。

```bash
pip install open-webui
open-webui serve
```

浏览器打开 http://localhost:8080 → 管理员面板 → Settings → Connections → OpenAI → **Add Connection**：
- URL：`https://www.aytdai.com/v1`
- API Key：你的密钥

保存后在聊天界面选模型即可。

## Grok CLI

```bash
npm install -g @vibe-kit/grok-cli
```

设置环境变量：
```bash
export GROK_BASE_URL=https://www.aytdai.com/v1
export GROK_API_KEY=sk-你的密钥
```

启动：
```bash
grok --model deepseek-v4-pro
```

## Droid

[Factory Droid](https://factory.ai) — 终端编程 Agent。

> 先清掉 `ANTHROPIC_AUTH_TOKEN` 环境变量（如果有）。

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

编辑 `~/.factory/config.json`：

```json
{
  "custom_models": [{
    "model_display_name": "deepseek-v4-pro",
    "model": "deepseek-v4-pro",
    "base_url": "https://www.aytdai.com",
    "api_key": "sk-你的密钥",
    "provider": "anthropic",
    "max_tokens": 64000
  }]
}
```

启动 `droid`，`/model` 选模型即可。

## OpenHands

[OpenHands](https://github.com/All-Hands-AI/OpenHands) — 开源 AI 编程 Agent（原 OpenDevin）。

```bash
pipx install openhands
```

启动后在 Web 界面配置：
- LLM Provider：OpenAI Compatible
- Base URL：`https://www.aytdai.com/v1`
- API Key：你的密钥
- Model：`deepseek-v4-pro`

或者命令行一步到位：
```bash
openhands --llm-model openai/deepseek-v4-pro --llm-base-url https://www.aytdai.com/v1 --llm-api-key sk-你的密钥
```

    model="deepseek-v4-pro",

## 通用排查

不管什么工具，连不上就查这几样：
1. 密钥 `sk-` 开头，没多余空格
2. Base URL 对不对（OpenAI 格式带 `/v1`，Anthropic 格式不带）
3. 余额够不够
4. 网络能不能打开 `https://www.aytdai.com`
5. 有没有残留的官方环境变量在覆盖
