# 定价与充值说明

## 计费模式

**预付费 + 按量计费**：
- 充值余额到账户
- 每次 API 调用按实际使用的 Token 数扣除余额
- 无月度费用，无隐藏费用
- 充值的额度永久有效

---

## 充值方式

| 方式 | 说明 | 到账时间 |
|------|------|----------|
| 支付宝 | 扫码支付 | 即时到账 |
| 微信支付 | 扫码支付 | 即时到账 |
| 兑换码 | 管理员发放的激活码 | 即时到账 |

### 充值金额
¥10、¥20、¥50、¥100、¥200、¥500（也可输入自定义金额）

### 充值步骤
1. 登录 [www.aytdai.com](https://www.aytdai.com)
2. 进入 **控制台** → **钱包**
3. 选择充值金额
4. 使用支付宝或微信扫码完成支付

## 额度管理

登录控制台可以查看：
- **当前余额** — 钱包页面显示实时余额
- **消费明细** — 日志页面记录每次 API 调用的详细消费
- **充值记录** — 钱包页面显示历史充值
- **数据导出** — 支持导出消费数据（管理员功能）

### 余额不足提醒
当余额低于 ¥1 时系统会提醒，建议及时充值以免服务中断。
