# 定价与充值说明

## 怎么收费的？

**用多少花多少，不用不花钱。**

- 你每次调用 AI，系统按"Token 数"扣钱（Token ≈ 字数）
- 发出去的内容算"输入"，AI 回复的算"输出"，输出比输入贵
- 没有月费、没有隐藏费用、充的钱永不过期

## 怎么充值？

1. 登录 [www.aytdai.com](https://www.aytdai.com)
2. 点 **控制台 → 钱包**
3. 选金额（¥10 / ¥20 / ¥50 / ¥100 / ¥200 / ¥500，也能自定义）
4. 支付宝或微信扫码
