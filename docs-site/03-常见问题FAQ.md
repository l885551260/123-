# 常见问题 FAQ

## 注册相关

**Q: 怎么注册？**
A: 打开 [www.aytdai.com](https://www.aytdai.com)，三种方式任选：用户名+密码、邮箱+验证码、手机号+短信验证码。

**Q: 注册要花钱吗？**
A: 不要。注册就送 ¥1 体验金，够你先试试。

**Q: 忘记密码了？**
A: 登录页点"忘记密码"，用邮箱或手机号重置。

**Q: 能改用户名吗？**
A: 不能改用户名，但可以改显示昵称（个人设置里）。

---

## 使用相关

**Q: API Key 是什么？在哪拿？**
A: 就是一个 `sk-` 开头的字符串，相当于你的"调用密码"。登录后 → 控制台 → 创建API密钥。

**Q: 地址（Base URL）填什么？**
A: 大部分情况填 `https://www.aytdai.com/v1`。例外：ChatGPT-Next-Web 只填 `https://www.aytdai.com`（它自己会加 /v1）。

**Q: 有哪些模型可以用？**
A: 目前 10 个，看 [首页的模型表](/) 或 [API 文档](01-API使用文档.md)。

**Q: 一个密钥能调所有模型吗？**
A: 能。除非你创建密钥时手动限制了可用模型。

**Q: 报错"model not found"？**
A: 模型名打错了。注意大小写和横杠，比如是 `deepseek-v4-pro` 不是 `Deepseek-V4-Pro`。

**Q: 支持流式输出吗？**
A: 支持。加 `"stream": true` 参数就行。

## 密钥（API Key）相关

**Q: 能创建多个密钥吗？**
A: 能。不同项目用不同密钥，方便管理。还能给每个密钥设：
- 模型限制（只能用指定模型）
- IP 白名单（只能从指定 IP 调用）
- 额度上限

**Q: 密钥泄露了怎么办？**
A: 马上去控制台禁用或删除那个密钥，再创建新的。
